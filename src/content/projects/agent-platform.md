# Zetesis Agent Platform

Zetesis Agent Platform is an open framework designed for coordinating multi-agent systems with deterministic execution guarantees, state management, and real-time observability.

## Key Highlights

- **Reactive Agent Coordination**: Seamless agent-to-agent communication and event streaming.
- **Built-in Tool Sandbox**: Secure, sandboxed execution environment for developer commands and script execution.
- **Modular Memory & Context**: Pluggable memory architectures supporting hierarchical knowledge graphs.
